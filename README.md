# Whack-A-Mole

Ett enkelt webbaserat Whack-A-Mole-spel byggt med HTML, CSS och JavaScript (ES-moduler). Spelet skapar spelbrädet dynamiskt med JavaScript och använder flexbox för layout. Mullvadar dyker upp slumpmässigt, och spelaren får poäng genom att klicka (eller trycka Enter/Space när cellen är fokuserad). Spelet har timer, missräkning, paussystem, svårighetsökning och game-over-skärm.



## Så här kör du projektet och spelar.
- Klona eller ladda ner projektmappen
- Öppna index.html i webbläsaren
- Tryck på Starta



## Teknisk översikt

### Tekniker:

HTML5, CSS (Flexbox), JavaScript (ES6-moduler).

### Tillgänglighet:

- aria-live för dynamisk statusinformation

- role="dialog" för game-over-overlay

- Fokusmarkering, tangentbordsnavigering och semantiska element
